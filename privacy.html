2. Zweck der Anwendung

„wenn-reels“ ist eine private Anwendung, mit der der Betreiber seine eigenen, selbst erstellten Videos auf seinen eigenen YouTube-Kanal hochlädt. Die Anwendung wird ausschließlich vom Betreiber selbst genutzt und richtet sich nicht an andere Personen.

3. Welche Google-Daten verwendet werden

Die Anwendung meldet sich über Google OAuth mit dem Google-Konto des Betreibers an und nutzt die YouTube Data API ausschließlich, um Videos des Betreibers hochzuladen sowie Titel, Beschreibung und Sichtbarkeit dieser Videos festzulegen.

  • Es werden keine Daten Dritter erhoben, gelesen oder gespeichert.
  • Es werden keine Kommentare, Abonnenten-, Zuschauer- oder Kontaktdaten abgerufen.
  • Die von Google ausgestellten Zugriffstoken werden nur auf den Systemen des Betreibers gespeichert und nur für den Upload verwendet.

4. Weitergabe von Daten

Daten werden nicht verkauft, nicht an Dritte weitergegeben und nicht für Werbung verwendet. Hochgeladene Videos werden an YouTube (Google LLC) übertragen, damit sie auf dem Kanal des Betreibers erscheinen.

5. Speicherdauer und Löschung

Zugriffstoken werden nur so lange gespeichert, wie die Anwendung genutzt wird, und können jederzeit gelöscht werden. Der Zugriff der Anwendung kann jederzeit in den Google-Kontoeinstellungen unter myaccount.google.com/permissions widerrufen werden.

6. YouTube und Google

Die Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Die Nutzung der über Google-APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
